# movie-explorer-app
A React Native movie discovery app using the TMDB API.
About my project: Movie Explorer is a mobile application that I created using React Native and Expo. The main purpose of this app is to help users find movies, search for movies, and see more information about them.

I used the TMDB API to get real movie information from the internet. Users can see popular movies, search for a movie by its name, and select a movie to see its details.



What My App Can Do

My application has three main screens.

1. Home Screen

The Home screen is the first screen users see when they open the app. It has a search bar where users can type a movie name. Users can also go to the popular movies section.

2. Movie List Screen

This screen shows the movies from the API. Users can see movie posters, movie names, and ratings. They can select any movie to see more information.

3. Movie Details Screen
4. This screen shows more information about the selected movie, such as its poster, title, rating, release date, and description.
